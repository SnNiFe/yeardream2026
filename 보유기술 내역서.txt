FRONT-END(HTML, CSS, JAVASCRIPT, JQUERY)
- 기본적인 서비스 페이지 설계 및 구현 가능
- JS 및 J-QUERY 를 활용한 기본적인 동적 기능 구현 가능
- daum map API 연동을 통한 지도 서비스 개발 가능
- Ajax 를 이용한 비동기 서비스 구현 가능

maria DB
- 기본적인 쿼리 사용 가능
- 정규화를 고려한 ERD 작성 가능
- JOIN 을 활용한 통계쿼리 작성 가능
- 복잡한 쿼리를 단순화 하기 위한 VIEW 활용 가능

SPRING
- 초기 프로젝트 구성 및 설정 가능
- mybatis 연동을 통한 DataBase 기능 활용 가능
- 기본적인 CRUD 서비스 구현 가능
- Transaction 을 통한 rollback 기능 구현 가능 
- Interceptor 를 활용한 로그인 체크 공통 기능 구현 가능
- Properties 이용한 설정 가능
- Restful Service 를 위한 API 설계 및 작성 가능 
- SPRING security 암호화를 활용한 회원가입 및 로그인 기능 구현 가능
