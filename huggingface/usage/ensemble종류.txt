soft voting(모든 모델은 공평하다)
결과 A = (80+60+11)/3 = 50
결과 B = (20+40+89)/3 = 50

weighted Average(공부 잘하는 애의 의견을 좀 더 듣자)
결과 A = (80*0.6)+(60*0.3)+(11*0.1)
결과 B = (20*0.6)+(40*0.3)+(89*0.1)

Stacking
메타모델이 다른 모델들의 결과를 조합해서 최종 결과를 낸다.
기본모델 - A, B, C
메타모델 - A, B, C 의 경향성을 학습
최종 결과: 메타모델이 기본모델들의 내용을 받아서 경향성을 반영해 최종결과 반환
